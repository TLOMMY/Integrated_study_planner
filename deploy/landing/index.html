主要功能

从开学导入课表，到期末复习冲刺

手机优先设计，电脑上同样好用；数据在网页、Windows 与安卓之间自动同步。

📅

课表

Excel / 教务网页 / 截图与 PDF（AI 识别）三种导入方式，单双周、节次时间、多套课表、课表分享码与导出图片。

✅

任务与日程

快速添加、子任务、标签与清单、提醒时间；日 / 周 / 月视图，电脑端拖拽改期，自动避开上课时间。

⏱️

专注

番茄钟、白噪音与自己的歌单、防切出提醒；专注状态跨设备同步，按科目统计学习时长。

🔥

成长

连续打卡、经验与等级、成就徽章、学习热力图、断签保护卡、学习小组排行榜与每周学习报告。

✨

AI 助手

对话式规划：先看课表和空闲时段再排任务，可推荐 B 站课程、按讲义章节排复习；所有改动先出卡片，确认后才导入。

🎨

多主题与离线

默认、深色与多款玻璃主题；断网时仍可查看课表和任务。也可以接入自己的大模型 Key 或使用本地规则引擎。
